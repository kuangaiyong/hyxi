====================================================================
 HYXi 舆情分析平台 —— 使用说明
====================================================================

这是一个免安装的便携包：解压到任意目录即可使用，不需要管理员权限，
不写注册表，不装 Python / Node.js。不想要了直接删掉整个文件夹。


--------------------------------------------------------------------
 一、运行环境
--------------------------------------------------------------------

  · Windows 10 / 11 64 位
  · Google Chrome —— 只有「采集」功能需要它

    采集脚本用真实 Chrome 驱动，这是刻意的选择（比起浏览器自带的
    模拟内核，真实浏览器的身份更自洽，被目标站点拦截的概率低得多）。
    没装 Chrome 不影响启动，也不影响配置模型、查看历史数据、导出报告，
    只有点「开始采集」时会失败。

    下载地址：https://www.google.cn/chrome/

  · 联网 —— 调用大模型接口和抓取数据都需要


--------------------------------------------------------------------
 二、启动
--------------------------------------------------------------------

  双击「启动 HYXi.bat」

  黑色命令行窗口会打印自检结果，随后自动打开浏览器：

      http://127.0.0.1:8000

  这个窗口就是服务本身，**不要关**。用完了关掉它即停止服务。


--------------------------------------------------------------------
 三、首次配置（按顺序做，大约五分钟）
--------------------------------------------------------------------

  1) 左侧「LLM 配置」
     填入大模型的 API Key、接口地址、模型名称，点「测试连接」。
     翻译和舆情分析都靠它，不配就只能采集不能分析。

     还可以另配一个「多模态模型」，用来读懂帖子里的图片。不配也能用，
     只是带图的帖子只按文字分析。

  2) 左侧「数据源」
     点「新增数据源」，选择采集器并填写参数。
     若该数据源需要登录，保存后点「录入凭据」填账号密码。

     密码用本机专属密钥加密后存储（密钥在 .env 文件里，首次启动自动生成）。
     系统任何界面和接口都不会把密码读回去。

  3) 需要登录的数据源，点「人工登录」
     会在**这台电脑的桌面上**弹出一个 Chrome 窗口，请在里面完成登录
     （包括短信验证码、安全检查这类需要人操作的步骤）。
     看到页面正常进入后关掉那个窗口即可，登录状态会被保存下来复用。

  4) 左侧「任务」
     用一句话描述要做什么，例如：
         采集数据，翻译成中文，导出Excel，分析舆情
     提交后可以实时看到进度，跑完自动跳到结果页。


--------------------------------------------------------------------
 四、数据在哪 / 怎么备份
--------------------------------------------------------------------

  全部在程序目录的 data 文件夹里：

      data\hyxi.db        数据库（帖子、译文、舆情结论、任务记录）
      data\media\         采集下来的图片
      data\logs\          运行日志，出问题时看这里
      .env                本机加密密钥

  备份 = 把整个程序文件夹复制一份。
  换电脑 = 把整个文件夹拷过去，双击启动即可（.env 要一起带走，
  否则已保存的数据源密码解不开，需要重新录入）。

  卸载 = 删掉整个文件夹。


--------------------------------------------------------------------
 五、常见问题
--------------------------------------------------------------------

  ● 杀毒软件报毒 / Windows 安全中心拦截

    程序是编译打包的可执行文件，部分杀毒软件会对这类文件误报。
    可在安全软件里把整个程序目录加入信任列表后重试。

  ● 提示「端口 8000 已被占用」

    多半是 HYXi 已经在运行了。先看看是不是已经有一个黑色窗口开着，
    或直接在浏览器里访问 http://127.0.0.1:8000

  ● 提示「没有检测到 Google Chrome」

    只影响采集，其余功能正常。装完 Chrome 重启程序即可。

  ● 采集时提示「需要人工重新授权」

    登录状态过期了。到「数据源」页点「人工登录」重做一次第三步。

  ● 页面打不开

    看那个黑色窗口里有没有 [失败] 开头的行，它会直接说明缺什么。
    也可以看 data\logs\app.log。


--------------------------------------------------------------------
 六、想让局域网里的其他电脑访问
--------------------------------------------------------------------

  默认只监听 127.0.0.1（本机），这是为了安全：**不设密钥时接口不鉴权**，
  任何能访问这个端口的人都能改模型密钥、导出全部数据。

  确实需要局域网访问时，用记事本编辑程序目录下的 .env，加下面三行：

      TWEAKERS_API_KEY=自己起一个足够长的密码
      TWEAKERS_HOST=0.0.0.0
      TWEAKERS_ENABLE_DOCS=false

  重启程序，然后在「LLM 配置」页把同一个密钥填进「接口密钥」一栏。
  没有这个密钥的人就访问不了。

  第三行是关掉接口文档页 —— 它本身不需要密钥就能打开，会把整个接口清单
  摆给同一网段里的所有人看。只在本机用时无所谓，开放出去就该关掉。


--------------------------------------------------------------------
 七、使用前请注意
--------------------------------------------------------------------

  部分社交平台的服务条款禁止自动化登录与内容采集，账号存在被封禁的
  风险。请使用专用账号，不要复用有价值的个人账号。

  采集节奏已被刻意放慢（随机间隔、定期休息、遇到限流主动停止），
  请勿自行修改以提高速度。
